# sng-trening

Адаптивный лендинг «Искусство гипноза. Глубины сознания» для очного тренинга «Все виды гипноза и гипнотерапии». HTML, CSS и JavaScript. Папка `dist/` содержит все файлы сайта, включая шрифты и изображения.

## Предпросмотр

В корне проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Откройте [локальный предпросмотр](http://127.0.0.1:8765/). Для просмотра без внешней сети доступны текст, фотографии и интерфейс. Встроенным плеерам и ссылкам на сайт организатора требуется интернет.

## Содержание и источники

- [SOURCE-NOTES.md](./SOURCE-NOTES.md) содержит выписку по потоку, условиям и источникам.
- [MEDIA.json](./MEDIA.json) содержит ссылки на исходные ролики, портреты, кадры и варианты просмотра.
- Дату потока, программу и стоимость меняют в `dist/index.html`. При смене даты обновите также разметку Event в этом файле и изображение `dist/assets/social.jpg`.
- Кнопки записи ведут к оплате и бронированию на действующем сайте организатора. Телефон, почта и Telegram также взяты с сайта организатора.
- Кнопки «Задать вопрос» на первом экране и у программы открывают форму, которая подготавливает письмо на официальный адрес. В форме есть ссылка на веб-форму организатора.
- При открытии видео загружается iframe VK. В двух тематических блоках есть запасной просмотр записей организатора на Vimeo. Доступность отдельных видеозаписей зависит от провайдера.

## Яндекс Метрика

В `dist/config.js` можно указать числовой ID счётчика. При значении `null` тег Метрики не загружается. Для целей JavaScript используются идентификаторы `header_enroll`, `hero_enroll`, `official_enroll`, `final_enroll`, `telegram`, `phone` и `video_open`.

## Подготовка к GitHub Pages

После согласования публикации разместите содержимое этой папки в репозитории `sng-trening`. В **Settings → Pages → Source** выберите **GitHub Actions**, затем вручную запустите **Publish to GitHub Pages**. Workflow публикует `dist/` и подставляет публичный адрес в canonical, Open Graph URL и URL карточки. Запуск при push отсутствует. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
